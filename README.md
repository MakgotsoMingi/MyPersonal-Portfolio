# Student Registration Tracker Scaffold

This is a Create React App project scaffold for a practical assessment on:
- useState
- useEffect
- controlled forms
- local array usage

## Important
This project includes:
- the student data
- the form
- the display layout

This project does not include:
- useState logic
- useEffect logic
- onChange handlers
- onSubmit handlers
- validation logic
- button logic

Students must complete the functionality themselves.

## Run the project
npm install
npm start
